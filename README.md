# ⚡ JARDYSON (Low-Level & Ops)

Focado em entender a tecnologia na raiz. Aprendi a dominar infraestrutura, redes e sistemas operacionais de forma 100% autodidata, utilizando um ambiente de terminal (Termux) direto no celular para validar teorias diretamente no hardware. 

Se o hardware limita, o software contorna.

---

### 🧬 INTERESSES REAIS
*   **Sistemas de Baixo Nível:** Lógica rígida e gerenciamento de memória (C++, C#, Rust).
*   **Infraestrutura & Redes:** Análise de tráfego, proxies, VPNs e mapeamento de portas de comunicação (80, 443, 22, 3389).
*   **Mobile Internals (Android):** Modificação de firmware, bypass de segurança de APIs (Play Integrity via Magisk) e ferramentas de terminal (ADB/Fastboot).

### 🧪 PRÁTICA QUE DESENROLO
*   **Versionamento & Deploy:** Fluxo de commits via Git/GitHub e deploy automatizado integrado ao Railway (com gerenciamento seguro de variáveis `.env`).
*   **Ambiente Linux:** Manipulação de arquivos, scripts e redes através de linhas de comando em emuladores de terminal.
*   **Análise de Diagnóstico:** Identificação de gargalos de rede (`netstat / ipconfig`) e leitura prática de logs de erro para correção rápida.
